# No13thfloor — the missing floor, investigated

The No13thfloor site: a Why Files-style case file on triskaidekaphobia, the fear that erased the 13th floor, with real photographs, pressable exhibits, proof games, Human Ascendancy primers, and the Dark Sector course.

Built as a real Astryx app: React 19 + Vite + StyleX + @astryxdesign/core. Source lives in ~/workspace/no13thfloor-port (not in this repo). This repo holds the built output only: `dist/` plus the `CNAME` for no13thfloor.org, published by GitHub Pages.

Live at https://no13thfloor.org/
